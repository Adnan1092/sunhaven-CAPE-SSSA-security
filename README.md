# Sunhaven Context-Aware Access and Shared-Device Session Security

This repository contains my individual technical contribution to the
Sunhaven Care Workforce IAM project.

My individual technical work focuses on two security artefacts:

1. CAPE - Sunhaven Context-Aware Access Policy Engine
2. SSSA - Sunhaven Shared-Device Session Assurance

## Current Development

CAPE is the current development focus.

The CAPE work is being developed systematically through:

- problem analysis
- security risk analysis
- proposed solution
- scope and boundaries
- security requirements
- security policies
- detailed component design
- implementation
- testing and validation
- evidence and evaluation

SSSA will be developed after the main CAPE implementation has progressed.

## Security and Privacy

Only fictional and sanitised test information will be used in this repository.
Passwords, access tokens, client secrets, real resident information and other
sensitive information must not be committed.
